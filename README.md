# Slot Game

Professional free-to-play HTML5 slot machine built with React, TypeScript, PixiJS, and Zustand.

Credits are fictional. There is no real-money gambling.

## Stack

- React 19 + TypeScript + Vite
- PixiJS 8 for canvas rendering
- Zustand for domain state
- Vitest for unit tests
- Tailwind CSS planned for HUD styling

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run format:check
npm test
npm run build
```
